# 温湿度グラフ作成ツール

温湿度データロガーなどが出力した CSV ファイルを読み込み、期間（○月○日～○月○日）を選んで
温湿度グラフを表示・保存する HTML ツールです。

- **`index.html` をダブルクリックするだけで動きます**（インターネット接続・インストール不要）
- データはブラウザの中だけで処理され、外部には送信されません
- Windows の Edge / Chrome、Mac の Safari / Chrome で動作します

---

## 使い方

1. `index.html` をダブルクリックして開く
2. 画面上部の枠に CSV ファイルをドラッグ＆ドロップ（またはクリックして選択）
   - 読み込むと「1. CSVファイルの読み込み」の枠は見出し1行だけに縮みます。
     別のファイルに差し替えたいときは、その見出しをクリックすると開きます
3. 「列の指定」が自動判定されます。違っていたらプルダウンで直して「この設定で読み込む」
4. 「開始日」「終了日」で期間を指定 → グラフが更新されます
   - 「全期間 / 直近1年 / 直近3か月 / 直近1か月 / 直近1週間」ボタン、「月単位」プルダウンでも選べます
5. 「PNG画像で保存」で画像ファイルとして保存、「印刷 / PDF」で紙・PDF に出力

## 対応する CSV の形式

| 例 | 対応 |
|---|---|
| `Date/Time,No.1,No.2` | ◎ **既定**（データロガーの標準形式。No.1=温度、No.2=湿度として自動設定） |
| `日時,温度,湿度` | ○ |
| `日付,時刻,温度(℃),湿度(%)` | ○（日付と時刻が別列でも可） |
| `No,日付,時刻,温度,湿度` | ○（余分な列があっても可） |
| 先頭にロガーの説明行がある | ○（自動で読み飛ばします） |
| 文字コード UTF-8 / Shift_JIS | ○（自動判定） |
| 日時の書式 `2024/1/1 9:30` `2024-01-01 09:30:00` `2024年1月1日 9時30分` | ○ |
| 値に単位付き `23.4℃` `55.0%` | ○（数値だけ取り出します） |

> **既定の列**：`Date/Time` を日時、`No.1` を温度、`No.2` を湿度として自動的に割り当てます
> （`No1` `CH1` などの表記ゆれにも対応）。別の列名の場合も、`日時／温度／湿度` などの
> 見出し語から自動判定し、それでも違うときはプルダウンで変更できます。

動作確認用のサンプルとして `sample_ondotori.csv`（`Date/Time,No.1,No.2` 形式・Shift_JIS・
2024年1年分・30分ごと）、`sample_data.csv`（`日時,温度,湿度` 形式・UTF-8）、
`sample_logger_sjis.csv`（日付と時刻が別列・説明行あり）を同梱しています。

## 表示の設定

| 項目 | 内容 |
|---|---|
| グラフタイトル | 図の上に出る見出し（例：収蔵庫 温湿度記録） |
| 温度を表示 / 湿度を表示 | 片方だけのグラフにできます |
| 目標湿度帯 | 管理目標とする湿度の範囲（初期値 55〜65%）を薄い帯と破線で表示 |
| データの表示方法 | 生データ／日平均／日平均＋日較差（帯）から選択 |
| 温度軸 最小・最大 | **既定は 0〜100℃**（右の湿度軸 0〜100% と目盛りがそろいます）。「自動」ボタンで表示中の期間のデータに合わせて拡大できます |
| 温度の表示名／湿度の表示名 | グラフ上部の凡例に出す名前。既定は **温度** と **湿度** |
| グラフ下の文章 | グラフの下に出す備考・考察など（改行可）。位置は**左寄せ／中央寄せ／右寄せ**から選択 |
| 文章を印刷に含める | チェックを外すと、印刷・PDF と PNG から文章を除きます（初期＝含める） |

> **印刷の体裁**：文章が **1〜3行**のときは、グラフの高さを自動で少し詰めて
> 「グラフ＋文章＋集計表」を**1ページに収めます**。文章が **4行以上**になると、
> 集計表は**次のページ**に送られます（グラフと文章は1ページ目）。
| 集計表を画面に表示 | 下の集計表を出す／出さない |
| 集計表を印刷にも含める | **印刷・PDF は既定でグラフだけ**。チェックを入れたときだけ集計表も一緒に印刷されます |

> 1年分など点数が多いデータは、読み込み時に自動で「日平均」表示になります。
> 「生データ」に切り替えると、1日の変動もそのまま描画されます（横1ピクセルごとに
> 最小〜最大を縦線でまとめて描くため、数万点でも高速に表示できます）。

## プログラムの構成（`index.html` の中身）

1ファイルで完結しています。JavaScript は役割ごとに関数（function）に分かれていて、
それぞれの先頭にコメントで説明を書いています。主なものは次のとおりです。

| 関数名 | 役割 |
|---|---|
| `readFileAsText(file)` | ファイルを読み込んで文字列にする。UTF-8 で読めなければ Shift_JIS で読み直す |
| `parseCSV(text)` | CSV 全体を 2次元配列（行×列）に変換する。説明行は読み飛ばす |
| `splitCsvLine(line)` | 1行を「,」で分割する。`"` で囲まれた中のカンマは区切りにしない |
| `parseDateTime(dateStr, timeStr)` | 文字列から日時（Date）を作る。和暦表記の記号や Excel のシリアル値にも対応 |
| `toNumber(s)` | `23.4℃` のような文字列から数値だけを取り出す |
| `guessColumns(header, sampleRow)` | 「日時」「時刻」「温度」「湿度」がどの列かを自動判定する |
| `buildRecords(rows, idx, hasHeader)` | 表を `{t:日時, temp:温度, hum:湿度}` の配列に変換し、時刻順に並べる |
| `filterByPeriod(list, from, to)` | 指定した期間（開始日0時〜終了日24時）でデータを絞り込む |
| `aggregateDaily(list)` | 1日ごとの平均・最高・最低にまとめる（長期間の表示用） |
| `computeStats(list)` | 期間内の最高・最低・平均・変動幅を計算する |
| `drawChart()` | 設定を読み取り、キャンバスにグラフ一式（枠・目盛り・線・凡例）を描く |
| `drawSeries(...)` | 折れ線1本を描く。点が多いときはピクセル列ごとの縦線でまとめて描く |
| `drawRange(...)` | 日較差などの「帯（塗り）」を描く |
| `niceTicks(min, max, target)` | 軸の目盛りを 1・2・5・10 …の切りのよい間隔で作る |
| `makeXTicks(from, to)` | 期間の長さに応じて横軸のラベルを作る（1年→月、数日→時刻 など） |
| `updateStats(list)` | 期間内の集計結果を表にして表示する |
| `fitTempAxis()` | 「自動」ボタン用。表示中の期間の温度に合わせて温度軸の範囲を決める |
| `updateNote()` | 入力された文章をグラフの下に表示し、寄せ（左・中央・右）を反映する |
| `wrapText(ctx, text, maxWidth)` | PNG保存用に、文章を指定幅で折り返して1行ずつの配列にする |
| `buildExportCanvas()` | PNG保存用の画像を作る。設定に応じてグラフの下に文章を描き足す |
| `printNoteLines()` | 印刷に出る文章の行数を数える（改行の数と折り返しを含む行数の多いほう） |
| `applyPrintLayout()` | 印刷直前に呼ばれ、行数に応じてグラフの高さを詰める／集計表を次ページへ送る |
| `restoreScreenLayout()` | 印刷後にグラフの高さを画面用に戻して描き直す |

### 色やデザインを変えたいとき

`index.html` の先頭の `<style>` の中、`:root { ... }` に色の設定があります。

```css
--temp-color:#d93a34;   /* 温度の線の色 */
--hum-color:#2d6cdf;    /* 湿度の線の色 */
```

グラフ内の色は `drawChart()` / `drawSeries()` の中で `"#d93a34"`（温度）、
`"#2d6cdf"`（湿度）として指定しているので、ここを書き換えると線の色が変わります。
